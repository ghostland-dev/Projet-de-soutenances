# Documentation de l'application E-tax

L'application E-tax est une application conçue en utilisant les frameworks Laravel, Jetstream, Fortify, Tailwind et Sancrum. Cette application a pour objectif de générer des dossiers de remboursement sur les taux fiscaux de TCGN et CSPE.

## Installation

Pour installer l'application, veuillez suivre les étapes suivantes :

1. Clonez le dépôt Github de l'application E-tax sur votre machine locale.
2. Exécutez la commande `composer install` pour installer toutes les dépendances de l'application.
3. Créez une base de données MySQL pour l'application.
4. Copiez le fichier `.env.example` et renommez le `.env`. Ensuite, modifiez les paramètres de connexion à la base de données dans le fichier `.env`.
5. Exécutez la commande `php artisan key:generate` pour générer une clé d'application.
6. Exécutez la commande `php artisan migrate` pour exécuter les migrations de la base de données.
7. Enfin, exécutez la commande `php artisan serve` pour lancer l'application.

## Utilisation

L'application E-tax est facile à utiliser. Une fois que vous êtes connecté, vous pouvez générer des dossiers de remboursement en suivant les étapes suivantes :

1. Cliquez sur l'onglet "Générer un dossier de remboursement".
2. Remplissez le formulaire avec les informations nécessaires.
3. Cliquez sur le bouton "Générer".
4. Un dossier de remboursement sera généré avec les informations que vous avez fournies.

## Conclusion

En conclusion, l'application E-tax est une solution efficace pour générer des dossiers de remboursement sur les taux fiscaux de TCGN et CSPE. Elle est facile à installer et à utiliser.
